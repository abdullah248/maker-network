# Sample design files

Drop these into the request builder at `/requests/new?profile=<slug>` to try the
upload flow without hunting for your own models.

| File | Use it for |
| --- | --- |
| `calibration-cube-20mm.stl` | FDM or resin 3D printing. A standard 20 mm calibration cube. |
| `keychain-blank.svg` | Laser cutting or engraving. An 80 x 50 mm keychain blank; red = cut, blue = engrave. |

Both are tiny plain-text files, so they upload instantly.
